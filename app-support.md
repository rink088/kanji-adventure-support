# Kanji Adventure Support

For help with Kanji Adventure, email [paperworkjapan.support@gmail.com](mailto:paperworkjapan.support@gmail.com).

**How do I study for free?** Open the Home tab and select Grade 1.

**How do I unlock Grades 2–6?** Select マイページ, complete the parent check, then choose the grade pack. The single purchase unlocks all five grades.

**How do I restore a purchase?** Use the Apple Account that bought the pack. Open the parent area and select 購入を復元 / Restore purchases.

**How do I move my learning progress to another iPhone?** Choose Export progress in the parent area. Save the file somewhere you can access on the other iPhone. On that iPhone, choose Restore progress and select the file. Restoring a backup replaces the learning progress currently on that device.

## 日本語サポート

お問い合わせは [paperworkjapan.support@gmail.com](mailto:paperworkjapan.support@gmail.com) までメールでご連絡ください。

小学1年生は無料です。ホームから「小学1年生」を選んでください。小学2〜6年生は「マイページ」の保護者メニューで、まとめて購入できます。

購入を復元するには、購入時と同じApple Accountを使い、保護者メニューの「購入を復元」を選んでください。

機種変更の前に保護者メニューから学習記録を書き出してください。新しいiPhoneで記録を復元すると、その端末の現在の学習記録が置き換わります。
